온라인 프랑스어 과외

Discord 화면 공유와 실시간 필기를 활용하는 1:1 맞춤 프랑스어 과외. 30분 단위 연장으로 바쁜 직장인의 시간을 유연하게 맞출 수 있습니다.

프랑스 원어민 강사가 한국어 설명과 프랑스어 몰입 코칭을 병행해 발음·회화·DELF 대비를 균형 있게 다룹니다.

30분 단위로 유연하게

  • 예약 — 기본 60분, 필요 시 30분 단위로 연장 가능.
  • 진단 — 레벨 체크와 발음 피드백으로 억양을 파악.
  • 수업 — 화면 공유·채팅·필기 공유를 동시에 활용.
  • 과제 — 요약 노트와 PDF 워크시트를 이메일로 보내드립니다.

온라인 프랑스어 과외 도구

Discord의 화면 공유와 디지털 화이트보드로 문장을 실시간으로 정리하고, 수업 직후에는 핵심 표현을 정리한 PDF와 링크를 이메일로 전달합니다. 노트북·마이크·이어폰만 준비하면 됩니다.

필요한 모든 교재와 예문은 화면에 띄워 공유하며, 과제 피드백은 요약 노트와 PDF 파일로 전달됩니다.

커리큘럼 예시

  1. 도입 10분 — Small talk + 전 회차 리뷰
  2. 핵심 30분 — 회화·롤플레이·발음 드릴
  3. 정리 15분 — 표현 정리, 어휘 확장, 발음 과제 안내
  4. DELF 옵션 — 시험식 타이머, 쓰기 과제, 채점 기준 피드백

온라인 프랑스어 과외 FAQ

수업 자료는 어떻게 제공되나요?

매 회차 직후 요약 노트와 필요한 표현을 PDF·링크 형태로 이메일로 보내드립니다. 추가 설명이 필요하면 문자나 메일로 언제든 질문을 남겨 주세요. 자료는 한국 내 이메일·메신저 계정으로만 전달합니다.

시간 변경은 어떻게 되나요?

24시간 전에는 무료로 일정 변경이 가능하며, 이후 변경은 1회 차감 정책을 따릅니다. 모든 일정은 한국 표준시(KST)로만 안내하고, 해외 체류 중에는 예약을 유지할 수 없습니다.

온라인 상담 안내

Discord 테스트콜 또는 30분 체험 수업을 원하시면 카카오톡/이메일로 문의해 주세요.
